# Proof of Concept Assets

Place the sanitised FastAPI sample application, JMeter test plans, and helper scripts here.

Suggested layout:

```text
poc/
├── fastapi-app/
├── jmeter/
└── scripts/
```

Review JMX files and scripts before publishing. Remove credentials, local file paths, bearer tokens, and environment-specific configuration. Do not commit JMeter result files (`.jtl`) or logs.
